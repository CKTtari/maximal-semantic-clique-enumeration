# 实验设计文档：Average-Constrained Maximal Semantic Clique Enumeration

> 本文档对应论文 Section 5 (Experiments)，覆盖 Exp-1 ~ Exp-8。所有实验基于 `alg1-raw.cpp` ~ `alg4-raw.cpp`，**禁止修改原始算法文件**；统计与自动化脚本另写新文件。
> 
> **关键原则**：所有测时间的实验必须使用原始 `algX-raw.cpp`（无统计计数器），以保证时间测量纯净准确。带统计器的 `-stats` 版本仅用于 Exp-4（Diagnostics）收集内部指标，不用于测时间。
> 
> **阈值策略**：
> - **默认代表阈值**：τ_80（用于除 Exp-1/2/4 外的所有实验）
> - **多阈值实验**：Exp-1（Overall Efficiency）、Exp-2（Scalability）需要在 τ_10、τ_50、τ_90 下分别测试
> - **敏感性扫描**：Exp-3 专门扫描 τ_10 到 τ_95

## 1. 编译规范

所有算法统一使用以下命令编译（来自 `其他要求.md`）：

```bash
g++ -O3 -march=native -fopenmp -std=c++17 alg1-raw.cpp semantic_graph.cpp -o alg1-raw.exe
g++ -O3 -march=native -fopenmp -std=c++17 alg2-raw.cpp semantic_graph.cpp -o alg2-raw.exe

g++ -O3 -march=native -fopenmp -std=c++17 alg4-raw.cpp semantic_graph.cpp -o alg4-raw.exe
```

- 环境：GCC 13.2+，支持 OpenMP 与 AVX2
- 运行平台：AMD Ryzen 9 7945HX (16 cores, 32 threads)，32 GB RAM，Windows 11 + MSYS2

## 3. 实验执行与数据收集

### 3.1 统一运行方式

所有算法均使用交互式命令循环，通过管道非交互执行：

```bash
# alg1 (StructBK) — 无 tau 参数
printf 'mine
quit
' | ./alg1-raw.exe dataset <ID> log exp1_alg1_ds<ID>.log

# alg2 (SemBK), alg3 (StrSub), alg4 (MonoSemMCE) — 需指定 tau
printf 'mine <tau>
quit
' | ./alg2-raw.exe dataset <ID> log exp1_alg2_ds<ID>.log
printf 'mine <tau>
quit
' | ./alg3-raw.exe dataset <ID> log exp1_alg3_ds<ID>.log
printf 'mine <tau>
quit
' | ./alg4-raw.exe dataset <ID> log exp1_alg4_ds<ID>.log
```

### 3.2 日志解析

所有算法日志均输出统一格式的总时间：

```
=== TOTAL: <ms> ms,  <count> maximal cliques ===
```

**`scripts/parse_log.py`** 自动从 `.log` 文件中提取：
- `total_ms`：总运行时间（毫秒 → 秒）
- `clique_count`：输出团数量
- `size_distribution`：各 size 的团数量及平均 size
- 对于 alg3：`phase1_ms`, `phase2_ms`, `phase3_ms`
- 对于 alg4：`ablation` 开关状态

## 4. 各实验详细设计

### Exp-1: Overall Efficiency（对应 Table 1）

**目标**：在 τ_10、τ_50、τ_90 下比较 4 个算法在数据集 1–5 7-9 上的端到端运行时间。

**算法**：
- `alg1-raw.exe` → **StructBK**（纯结构 MCE，无语义约束，仅作参考）
- `alg2-raw.exe` → **SemBK**
- `alg3-raw.exe` → **StrSub**
- `alg4-raw.exe` → **MonoSemMCE**

**表格格式**：每数据集占 6 列（alg1 的 T/O + alg2 的 T/O + alg3 的 T/O + alg4 的 T/O，按 τ_20/τ_50/τ_80 分组），或更紧凑地按算法×阈值展开列。

**执行**：对每个 (dataset, τ) 组合运行 alg1–alg4，τ ∈ {τ_20, τ_50, τ_80}。

**数据收集**：每个 (算法, 数据集, τ) 组合运行 **3 次**，取平均 wall-clock 时间（秒）。

**输出表格**：Table `tab:exp1`，列格式为 Algorithm | alg1 | alg2(τ20) | alg2(τ50) | alg2(τ80) | alg3(τ20) | ... | alg4(τ80)。TLE 记为 >3600s（论文），实际运行超时 600s。OOM 记为 >24GB。

**验证**：alg2/alg3/alg4 的输出团数量差距必须 ≤ 3（确认正确性）。

---

### Exp-2: Scalability（对应 Figure 2）

**目标**：在 DBLP（数据集 9）和 Amazon（数据集 10）上，测量运行时间随图规模（边数）增长的变化。

**子图**：使用预生成的 `dataset/scale_datasets/` 中的 6 个比例子图（L1–L6）。

**执行**：对 6 个子图分别运行 alg2, alg3, alg4（alg1 作为参考可选）。
- 每个子图在 τ_20、τ_50、τ_80 下分别测试。
- 额外增加 τ_90 下的 MonoSemMCE 曲线（虚线）。

**输出**：两个 log-log 坐标图（DBLP / Amazon），横轴 Edges，纵轴 Time(s)。每个图包含 3 组曲线（对应 τ_10, τ_50, τ_90）。

---

### Exp-3: Sensitivity to τ（对应 Figure 3）

**目标**：在数据集 1, 5, 7, 8 上，扫描 τ 从 50th 到 95th percentile，测量运行时间。

**τ 取值**：50, 60, 70, 80, 90, 95 percentile。

**执行**：对每个 (dataset, τ) 组合运行 alg2, alg3, alg4。

**输出**：4 个 semilogy 子图（每个数据集一个），横轴 τ percentile，纵轴 Time(s)。

---

### Exp-4: Search Process Diagnostics（对应 Table 4）

**目标**：收集内部搜索统计量，解释性能差异根源。

**需要统计的指标**：
- **alg2 (SemBK)**：`expansion_calls`, `similarity_lookups`, `output_count`
- **alg3 (StrSub)**：`phase1_structural_cliques`, `phase2_candidates`, `similarity_lookups`, `output_count`
- **alg4 (MonoSemMCE)**：`expansion_calls`, `w_prune_triggers`, `mono_break_triggers`, `similarity_lookups`, `output_count`

**实现方式**：创建 `src/alg2-stats.cpp`, `src/alg3-stats.cpp`, `src/alg4-stats.cpp`，复制原文件并添加原子计数器。**这些版本仅用于收集统计量，不用于时间测量。**

**执行**：数据集 1–5 7-9，τ_10、τ_50、τ_90（展示不同选择性下的内部行为差异）。

**输出表格**：Table `tab:exp4`，按算法分组，8 列（数据集 1–8），可能分 τ 展示。

---

### Exp-5: Parallel Scalability（对应 Figure 4）

**目标**：测量线程数从 1 到 128 时的加速比，以及负载均衡性。

**方法**：
- 固定数据集 2。
- 通过环境变量 `OMP_NUM_THREADS` 控制线程数：1, 2, 4, 8, 16, 32，64，128。

**执行**：在 τ_80（默认）下测试 alg2, alg3, alg4。。

**加速比计算**：`speedup(t) = time(1 thread) / time(t threads)`

**负载均衡**：在 `-stats` 版本中为每个线程记录处理的 expansion/seed 数量。

**输出**：左图 speedup 曲线（1–128 线程），右图 128 线程 workload share boxplot。

---

### Exp-6a: Ablation Study on MonoSemMCE（对应 Table 5）

**目标**：验证 alg4 中各剪枝组件的独立贡献与组合效果。

**变体**（通过编译时 `-D` 宏或 `sed` 修改副本实现）：
1. **No pruning**：`ENABLE_W_PRUNE=0`, `ENABLE_MONO_PRUNE=0`, `ENABLE_LAYER_DEDUP=0`
2. **W-pruning only**：`ENABLE_W_PRUNE=1`, `ENABLE_MONO_PRUNE=0`, `ENABLE_LAYER_DEDUP=0`
3. **Monotone break only**：`ENABLE_W_PRUNE=0`, `ENABLE_MONO_PRUNE=1`, `ENABLE_LAYER_DEDUP=0`
4. **Both, no layer dedup**：`ENABLE_W_PRUNE=1`, `ENABLE_MONO_PRUNE=1`, `ENABLE_LAYER_DEDUP=0`
5. **Full MonoSemMCE**：`ENABLE_W_PRUNE=1`, `ENABLE_MONO_PRUNE=1`, `ENABLE_LAYER_DEDUP=1`

**实现方式**：`scripts/build_ablation.sh` 通过 `sed` 临时生成变体代码，编译后删除。

**执行**：数据集 1, 5, 7, 8，τ_90（默认代表）。

**输出表格**：Table `tab:exp6a`，4 列（数据集），5 行（变体）。

### Exp-6b: Ablation Study on StrSub（对应 Table 6）

**目标**：验证 alg3 中 Top-Edge Layer Pruning 与 Local Maximality Filter 的贡献。

**变体**：
1. **No pruning, no filter**：关闭 Top-Edge 与 local max filter
2. **Top-Edge pruning only**：仅启用 Top-Edge
3. **Local max filter only**：仅启用 local max filter
4. **Full StrSub**：两者全开

**实现方式**：与 Exp-6a 类似，通过编译时脚本生成变体。

**执行**：数据集 4, 8，τ_10 30 60 90测四个阈值对比。

**输出表格**：Table `tab:exp6b`。

### Exp-7: Engineering Optimizations（对应 Table 7）

**目标**：量化各工程优化对 alg4 的贡献。

**测试配置**（在 alg4 基础上逐项禁用）：
1. **Dense bitmap**：将 `BlockedSparseBitmap` 替换为稠密 bitmap
2. **Naïve intersection**：不使用 bitmap，直接用 `std::set_intersection`
3. **No incremental acc**：在 expand 时重新计算 `acc'` 从 scratch
4. **No reorder caching**：跳过 `GraphReorder` 的 BFS 重排序
5. **Full system**：全部启用

**实现方式**：创建 `src/alg4-engineering.cpp`，复制 alg4 并通过条件编译切换各优化。

**执行**：数据集 1, 2, 8, 9，τ_90（默认代表）。

**输出表格**：Table `tab:exp7`。

---

### Exp-8: Result Quality on DBLP（对应 Table 8）

**目标**：定性分析 DBLP 上发现的代表性 clique 的语义一致性。

**方法**：
- 在数据集 9（DBLP）上运行 alg1（StructBK）和 alg4（MonoSemMCE），τ_80。
- 对 alg1 的输出，随机抽样若干大团，计算其 avgSim。
- 对 alg4 的输出，选取高 avgSim 的代表性团（如计算机体系结构、算法理论等子领域）。
- 需要 DBLP 作者名到顶点 ID 的映射，用于人工解读。

**脚本**：`scripts/analyze_dblp_cliques.py`

**输出表格**：Table `tab:case`，列：Algorithm, Size, Avg.sim, Characteristic。

## 8. 已确认事项

2. **内部统计器**：允许创建 `alg2-stats.cpp`, `alg3-stats.cpp`, `alg4-stats.cpp`（复制原文件并添加计数器），仅用于 Exp-4。
3. **Baseline**：论文中无 Baseline 算法，只有 StructBK（alg1）作为结构参考。
4. **DBLP 作者映射**：原始数据在 `dataset/dblp-raw/`，需自行解析。
5. **τ 值**：预先计算并保存到 `scripts/tau_values.json`。
6. **Ablation 变体**：接受通过编译时脚本（`sed` + 临时文件）生成变体，编译后删除。
7. **子图**：已预生成在 `dataset/scale_datasets/`，无需重新生成。
8. **密度实验**：已删除（原 Exp-3）。
