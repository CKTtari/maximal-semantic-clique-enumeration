# 实验协议与参数选择

本文档冻结当前论文实验的资源限制、阈值、重复次数和数据接收标准。手工终端输出只用于调试；进入论文的结果必须由 `scripts/run_experiments.py` 生成、由 `scripts/archive_results.py` 归档，并由标准导出脚本写入 `tex-data/data`。

## 1. 资源与计时

- 每个 C++ 进程受 16 GiB 硬内存限制，超限记为 OOM。
- 除并行实验外统一使用 32 个 OpenMP 线程；并行实验使用 1、2、4、8、16、32 线程。
- 算法内部截止时间关闭，由外部 runner 对每个进程执行 1200 秒正式上限。相关团枚举研究采用过 1000 秒和 1800 秒上限，1200 秒在本机实验规模与可复现成本之间取中间值。
- 完成态配置独立运行三次，报告 raw 程序的算法时间中位数和最小--最大范围。TLE/OOM 运行一次，不重复已确定的删失状态。
- raw 程序用于时间与峰值内存；stats 程序只用于机制计数。stats 时间不进入效率表。
- 旧实现与新实现的正确性/工程对照只选择旧实现本身可在 180 秒内完成的参数。该值不是论文正式 TLE，也不是算法必须三分钟完成的要求。

1200 秒选择参考 [Efficient Signed Clique Search in Signed Networks](https://ronghuali.github.io/PaperFiles/Efficient%20Signed%20Clique%20Search%20in%20Signed%20Networks.pdf) 和 [Enumerating Cliques of Hypergraphs](https://www.labri.fr/perso/lsimon/downloads/papers/ictai25.pdf)。前者的枚举实验采用 1000 秒限制，后者采用 1800 秒限制并把未完成运行作为删失结果。

## 2. 阈值规则

绝对余弦阈值不能跨向量来源直接比较。每个数据集的候选阈值由现有结构边的 float32 余弦相似度分布确定，分位数计算与矿工使用同一向量、归一化和点积语义。

主表统一使用 q20、q80、q99。阈值敏感性实验在 ogbn-arxiv 上使用 q5、q20、q50、q70、q80、q90、q95、q97、q99；sc-ldoor 只复用主表三点。规模实验使用 q20、q50、q80、q90、q95、q99。q0 只用于退化边界正确性，不进入性能表。任何阈值都不得在观察单个算法胜负后调整。

每个完成配置记录 ACMSC 总数、大小直方图、算法时间、墙钟时间和峰值内存。stats 配置另记录搜索状态、候选测试、剪枝和包含过滤计数。算法间共同完成时至少核对总数和每个大小层；选定正确性配置还必须比较完整规范化集合。

## 3. 数据角色

主表八图为 FB15K-237、WN18RR、ogbn-arxiv、email-Enron、sc-nasasrb、sc-pkustk11、sc-pwtk 和 sc-ldoor。前三个使用自然语义向量；后五个使用公开真实图结构和固定种子生成的 256 维单位向量。生成的是属性，不是图、边或实验结果。

规模实验从 ogbn-arxiv 生成确定性的嵌套完整诱导子图。顶点按源图度数降序排列，以原始标识符打破并列；每个层级保留选中顶点之间的全部源边，并按同一映射复制官方特征。映射、构造规则与输入/输出 SHA-256 均保存在数据归档中。

AMiner 不作为候选。DBLP、Products、com-Amazon、soc-buzznet、soc-digg 和 tech-as-skitter 的既有数据与诊断结果保留，但不进入当前主表；不以单方法压力结果替代八图共同比较。

## 4. 影响范围与重跑

重跑由行为影响决定。修改某算法的搜索、后处理、计时边界、统计开关或输入时，只重跑受影响的方法与实验。无关的数据集映射增加、文档或绘图修改不要求重跑算法。旧结果可继续使用的前提是核心方法源码、图/vector 输入、阈值与统计口径均未受改动影响，并能由 manifest 追溯。

当前 Alg3/Alg4 的主表、阈值、规模、并行、消融和机制数据均来自包含过滤优化后的代码。Alg1/Alg2 的核心源码与继续使用的既有正式结果一致。Alg3 消融在优化后重新运行，所有变体的结果集合和大小直方图一致。

## 5. 接收与导出

runner 每批最多执行八个尝试；发生 crash、解析失败、TLE 或 OOM 时保留状态和日志。重跑必须使用新的 attempt 并记录原因。归档 manifest 保存计划、源码与可执行文件指纹、运行时输入哈希、结果状态及产物哈希。

`src/experiments/standard/paper_results_export.py` 是论文数据的唯一导出入口。它只读取 `experiments/summaries` 中列明的正式归档，不读取临时日志，也不把 pilot 时间写入论文。绘图脚本只读取 `tex-data/data`。表格、正文和图中的数字必须能逐层追溯到 CSV、summary、manifest 和原始任务记录。
