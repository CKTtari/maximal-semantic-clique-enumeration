# Alg4 Canonical-Parent DFS 正确性审计

## 1. 目标语义与实现边界

目标 maximal 语义是包含极大：合法团 `C` 不存在任何合法严格超集。标准实现 `src/alg4-raw.cpp` 与论文现在统一使用 `avg(C) >= tau`：根边、中间状态和终止候选均允许等号。旧分层参考实现仍保留其历史上的严格根/终止边界，仅用于解释旧结果，不再作为标准语义。

记 `k = |C|`，`S(C)` 为 `C` 中所有无序点对的相似度总和，`E_k = k(k-1)/2`，并定义顶点 `v` 在 `C` 中的相似度贡献：

```text
A_C(v) = sum_{u in C, u != v} sim(u,v).
```

## 2. 已采用规则及其反例审查

### 2.1 根只取高相似边

规则：只从 `sim(u,v) >= tau` 的结构边启动搜索。

完备性理由：对任何合法团 `C`，沿第 2.2 节的 canonical parent 反复删除顶点时，平均相似度不下降，因此最终二元父团的唯一边满足 `sim(u,v) >= avg(C) >= tau`，必然出现在根集合中。

边界审查：若根条件错误地写成严格 `>`，平均值恰好等于 `tau` 的合法团可能只包含相似度等于 `tau` 的边，从而漏解。标准实现因此在根与终止位置都使用 `>=`。

### 2.2 删除相似度贡献最小的顶点作为唯一父团

规则：对大小至少为 3 的合法团 `C`，删除 `A_C(v)` 最小的顶点；若并列，删除顶点 ID 最小者。记所得父团为 `P(C)`。

因为

```text
sum_{v in C} A_C(v) = 2S(C),
```

最小值满足 `A_C(v) <= 2S(C)/k`。于是

```text
avg(C - {v})
  = [S(C) - A_C(v)] / E_(k-1)
  >= S(C) / E_k
  = avg(C).
```

所以合法团的 canonical parent 一定合法。顶点 ID 只用于确定性地打破并列，不参与合法性判断，因此父团存在且唯一。

已检查的潜在反例包括负相似度、零相似度、所有顶点相似度贡献相等以及多个最小值并列。上述证明只使用有限实数的求和恒等式，对这些情况仍成立。实现使用 `long double` 累加由 `float` 边权提升后的顶点相似度贡献，避免不同插入顺序的普通 `float` 舍入改变父顶点。

### 2.3 正向只接受 canonical child

规则：从 `C` 尝试加入 `v` 得到 `D` 时，仅当 `P(D) = C`，即 `v` 正好是 `D` 的 canonical deletion，才递归进入 `D`。

完备性：任意合法团反复应用 `P` 都会使大小减一并保持合法，最终到达已枚举的合法边根。反向沿这条唯一父链时，每一步都会被接受。

无重复性：大小大于 2 的合法团只有一个 `P(D)`，因此只能从一个父状态生成；二元根本身也只枚举一次。该性质同时覆盖同一种子和跨种子的重复路径，不依赖哈希或 visited。

### 2.4 W 单步合法性过滤

规则：对当前 `k` 团 `C` 和候选 `v`，令 `delta(v) = sum_{u in C} sim(u,v)`，只在

```text
W(C) + delta(v) - tau*k >= 0
```

时把 `C union {v}` 视为合法中间状态，其中 `W(C) = S(C) - tau*E_k`。

该条件与 `S(C union {v}) >= tau*E_(k+1)` 代数等价，所以它只排除当前不合法的孩子，并没有假设“不合法孩子不存在合法多步超集”。canonical parent 定理保证每个目标答案存在一条所有前缀均合法的父链，因此跳过当前非法孩子不会破坏完备性。

反例审查：把此规则扩大成“当前不存在合法单点扩展就剪掉所有可能超集”是错误的，因为平均约束非单调；新实现没有采用这种多步推断。

### 2.5 候选交集

规则：加入 `v` 后，下一候选集合只保留同时属于旧候选集合且与 `v` 相邻的顶点。

归纳地，旧候选与当前团中每个顶点相邻；再与 `N(v)` 相交后，保留顶点与新团中每个顶点相邻。被删除顶点不可能形成结构团扩展，因此该过滤没有语义反例。

### 2.6 终止候选与包含过滤

规则：只有当不存在任何合法单点扩展时，当前合法团才进入候选集合；搜索结束后，删除所有被更大候选包含的团。

任何包含极大合法团必然没有合法单点扩展，所以一定进入候选集合。反过来，一个没有合法单点扩展的团仍可能存在合法多点超集，因此不能直接输出。若候选 `C` 不是包含极大，则有限图中存在一个包含它的包含极大合法团 `M`；`M` 没有合法单点扩展并会被完整搜索枚举，最终包含过滤会删除 `C`。因此“完整 canonical 枚举 + 终止候选 + 全局包含过滤”与包含极大定义一致。

## 3. 明确未采用的规则

这里必须区分两个不同命题。第 2.2 节的“删除相似度贡献最小顶点后仍合法”是当前 Alg4 的核心定理，数学上成立，代码也依赖它来确定唯一父团。旧分层程序还使用过另一条“候选排序后缀提前终止”规则；那只是旧遍历顺序上的加速条件，不是上述定理，也不是当前 canonical DFS 完备性所需的条件。

- 未使用“一步不可扩展即可直接输出”，因为存在多点联合恢复平均值的反例。
- 未使用 per-root visited，因为它不能跨根消重；哈希指纹还会引入碰撞正确性风险。
- 未使用分层 dedup，因为 canonical parent 已在生成前保证唯一性。
- 未使用旧分层程序的候选排序后缀提前终止规则。其数学不等式在精确实数模型下成立，但旧代码的 `float` 累加与边界比较可能提前终止；当前 Alg4 不需要这条规则。
- 未实现 multi-step surplus upper bound。方案中的放松上界还需要独立 oracle 和边界测试，不能在本轮正确性基线中与 canonical 改造同时引入。

真实数据给出了这条旧提前终止规则的浮点边界例。在 DS7、`tau=0.6` 上，团 `{1724, 6938, 7684, 7889}` 按两份程序共同使用的 AVX `float` 边相似度具有 `W=0.0014852285>0`。旧分层实现的比较量只相差一个 `float` ULP，因而提前终止并漏掉该团。Alg3 与当前 Alg4 都返回该合法团，完整集合也一致。这个例子说明旧浮点剪枝存在边界误差，不是否定相似度贡献删除定理。

回溯累加器也不能使用 `x += s` 后再以 `x -= s` 恢复。DS7 的深层搜索显示，这种逆运算经过大量兄弟分支后会积累舍入漂移，把一个真实为正的子状态余量改成负数。新实现改为进入分支前保存旧值，退出时直接覆盖恢复；成员相似度贡献使用相同策略。

## 4. 验证顺序

1. 使用整数边权和有理阈值的独立穷举 oracle，比较全部合法团、终止候选和最终包含极大输出集合。
2. 加入专门反例：无合法单点扩展但存在合法多点超集、顶点相似度贡献并列、负相似度和阈值相等。
3. 编译新实现后，在真实数据上同时保存两个实现的完整团集合；排序后逐行比较，而不只比较总数。
4. 完整集合一致后，再比较总数、按团大小计数、总时间和 peak memory。
5. 只选择原分层版自身能在 180 秒内完成的参数做新旧对比；这只是测试参数筛选规则，不是要求算法在三分钟内结束。优先保留 60 秒内完成的高 `tau` 用例。

## 5. 当前验证结果

采用 `>= tau` 边界的独立整数 oracle 已检查 40,001 个图/权重/阈值实例，其中包含最终平均值恰好等于阈值、但两个单点扩展均非法的显式反例。canonical 搜索生成的全部合法状态与暴力枚举完全一致，没有遗漏或重复；最终包含极大集合也完全一致。

DS7、`tau=0.6` 上，Alg3 独立得到 4,150 个结果，其完整团集合与 canonical 逐团相同；相对旧分层也只多出同一个 size-4 团。Alg3 的按大小分布同样与 canonical 完全一致。该交叉验证与直接 surplus 重算共同确认，差异来自旧分层的一个 ULP monotone-break 误剪，而不是 canonical 搜索的错误扩展。

在已测的 `tau >= 0.6` 配置中，最大差异为 1，且始终是 canonical/Alg3 多出同一个经过独立验证的合法团；`tau >= 0.61` 的 DS7 配置以及 DS8 的 0.6/0.8 均完全一致。该结论只覆盖表中阈值，不外推到尚未运行的中低 tau 区间。
