# 四算法实验执行 Checklist

本清单约束当前本地实验。研究范围暂时只包括 StructBK、SemBK、StrSub
和 MonoSemMCE；外部 baseline 暂缓。任何主实验开始前，A--G
必须完成，实验数据回填前必须完成 H。

## A. 定义、伪代码与实现对齐

- [x] 固定 ACMSC 为包含极大：不存在任何严格超集同时满足结构团与平均约束。
- [x] 核对相似度、`simSum`、`avgSim`、surplus 和阈值边界统一使用 `>= tau`。
- [x] StructBK 仅枚举结构极大团，论文明确其输出任务与其他三种方法不同。
- [x] SemBK 的无 pivot 搜索、候选集合、终止条件和 Check 包含验证与伪代码逐项对应。
- [x] StrSub 的结构 BK、Top-Edge bound、逐顶点上界、局部包含过滤和全局包含过滤与伪代码逐项对应。
- [x] MonoSemMCE 的可行根、canonical parent、W 判定、精确回滚和最终包含过滤与伪代码逐项对应。
- [x] 四个标准入口使用同一数据集映射、线程参数、内存限制、超时语义和日志字段。
- [x] 对小图运行独立穷举 oracle，比较完整输出集合，不只比较总数。
- [x] 对真实数据保存规范化结果集合，核对 SemBK、StrSub、MonoSemMCE 的总数和各 size 层数量。
- [x] 检查恰好等于 `tau`、负相似度、最小相似度贡献并列和无单点扩展但有合法多点超集等边界用例。

## B. 资源限制与实验规范

- [x] 查阅团枚举/社区搜索原论文，记录 TLE、内存、线程、重复次数和失败报告方式。
- [x] 在方案中区分实现筛选超时和论文正式实验 TLE。
- [x] 固定 C++ 进程内存上限为 16 GiB，OOM 不允许通过系统换页伪装成完成。
- [x] 固定最多 32 个 OpenMP 线程，并记录实际硬件与编译器版本。
- [x] 正式计时采用独立进程、预热后重复运行，报告中位数和离散范围。
- [x] TLE/OOM 作为删失结果保留，不用部分输出冒充完整结果。

## C. Tau 选择

- [x] 从真实图边相似度分布计算候选分位点，不手工为单个算法指定阈值。
- [x] 先在少量代表数据集上运行固定 pilot 网格，定位低、中、高选择性区间。
- [x] 主表参数在实验前按统一规则冻结，覆盖 StrSub 优势区间和 MonoSemMCE 优势区间。
- [x] 避免输出为空、全部边都可行或所有算法都瞬时完成的无信息参数；`q0` 仅保留为正确性边界，不进入性能表。
- [x] 用固定边相似度分位点记录阈值选择性，并在正式记录中保留输出量和结果规模分布。

## D. Raw 与 Stats 分离

- [x] `*-raw` 二进制不执行逐状态统计、直方图原子更新或诊断输出。
- [x] `*-stats` 由同一标准源码通过编译开关生成，不复制算法主体。
- [x] stats 模式记录各算法适用的 generated states、candidate tests、prunes、dedup 和层级计数。
- [x] raw 与 stats 在同一参数上输出集合完全一致。
- [x] 论文效率表只使用 raw；机制表只使用 stats，并明确两者不能混用计时。

## E. 特殊数据集与规模变体

- [x] 规模实验只从公开真实图及其真实向量派生；主表中的生成属性只用于公开真实图，采用固定种子并与自然语义结论分开。
- [x] 规模实验使用确定性的真实图诱导子图，给出顶点选择规则和嵌套关系。
- [x] 子图重新编号时同步重排向量，自动验证图顶点数、向量数和原 ID 映射。
- [x] 保存 provenance、参数、原始文件校验和、派生文件校验和及构造日志。
- [x] 每个规模级别报告 V、E、平均度、最大度、退化度和三角形/团相关统计。
- [x] 不把仅缩短边文件但复用未对齐向量的文件用于实验。

## F. 消融与组件开关

- [x] StrSub 的 Top-Edge bound、逐顶点上界和 local-max filter 均有独立编译开关。
- [x] MonoSemMCE 的 W 判定、canonical ownership 与工程组件按“可关闭且仍正确”或“定义性组件不可关闭”分类。
- [x] 定义性组件不伪装成普通消融；替代生成策略单列为机制研究。
- [x] 所有变体从同一源码构建，构建脚本记录宏、编译命令和源码 commit。
- [x] 每个变体先过输出集合一致性检查，再允许计时。

## G. 自动化运行与数据记录

- [x] 一个本地 runner 负责编译、运行、硬超时、峰值内存、日志和结果清单。
- [x] 任务清单采用结构化配置，包含 dataset、algorithm、mode、tau、threads、repeat 和 TLE。
- [x] runner 每批只执行少量任务，默认遇到 crash、集合不一致或解析失败立即停止。
- [x] 每个任务独立进程、独立日志、独立 stdout/stderr 和机器可读 JSON 记录。
- [x] 支持断点续跑，但不自动跳过失败任务；重跑原因必须记录。
- [x] 数据文件、可执行文件和编译产物继续由 Git ignore，并归入 `no-use` 或实验输出目录。
- [x] 运行前记录图、向量索引及全部分块 SHA-256；归档时重新校验并使用仓库相对路径。
- [x] 历史运行缺少运行时输入/源码快照时明确标记 legacy，不伪装为完整可复现实验。

## H. 小批实验与质量检查

- [x] Batch 0：四算法构建与小图 oracle。
- [x] Batch 1：2 个数据集乘少量 tau 的 pilot，确认输出和运行区间。
- [x] Batch 2：冻结 tau 后运行四算法主效率小表。
- [x] Batch 3：只对代表数据集运行 stats，不复用 stats 时间。
- [x] Batch 4：运行 StrSub 精确消融等价性与 MonoSemMCE 机制计数。
- [x] Batch 5：运行真实图嵌套规模变体和线程扩展。
- [x] Batch 7：补齐 WN18RR `q20` 和 email-Enron `q20/q80/q99` 三次正式重复，并归档 manifest、summary 和数据 provenance。
- [x] 主表冻结为 8 个公开数据集，全部采用统一的 `q20/q80/q99` 网格，不再划分单独压力组。
- [x] StrSub 在主表 24 个配置中完成 22 个；两个未完成单元均按正式 TLE 保留。
- [x] Batch 11--12：补齐主表空缺、阈值区间、嵌套规模、线程扩展、当前消融和阶段归因；只重跑受算法实现变化影响的实验。
- [x] 每批检查结果数、size 分布、运行时间、峰值内存和关键计数器的数量级关系。
- [x] 异常结果先复现和定位，不继续扩大批量。
- [x] 保留不符合预期但正确的原始记录；论文只形成有证据支持的正向技术论述，不编造结论。
