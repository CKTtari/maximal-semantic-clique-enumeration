# ACMSC 算法改进、外部基线与实验重构方案

## 0. 方案结论

本项目保留三条清晰的算法主线：SemBK（Alg2）作为直接而低效的语义改造基线，StrSub（Alg3）作为结构分解驱动的工程路线，MonoSemMCE（Alg4）作为由单调路径性质驱动的理论路线。ACMSC 采用包含极大（inclusion-wise maximal）定义。canonical reverse search 已成为标准 `src/alg4-raw.cpp`：它为每个合法团定义唯一合法父状态，以 DFS 消除重复插入路径和整层状态存储，并在末端执行全局包含过滤。论文定义、伪代码、正确性论证和 `>= tau` 边界已与该实现统一。多步可行性上界仍是经过证明但尚未实现、需要独立性能验收的后续优化。

实验部分从当前的 8--9 个编号实验收敛为 6 个研究问题（RQ），其中第六项专门讨论结果质量。VLDB 没有规定必须完成多少个实验；重点是每项核心声明是否有直接证据、结果能否复现，以及是否覆盖效率、规模、机制和适用边界。当前任务量本身不一定过高，但实验之间的参数、编号和实现版本不一致，导致证据链分散。

## 1. 首先必须解决的 P0 问题

### 1.1 maximal 已确定为包含极大，TeX 已完成修正

ACMSC 的目标定义已经确定为包含极大：合法团 C 是 maximal，当且仅当不存在合法严格超集 C' supersetneq C。旧 `main.tex` 将其写成不存在单个顶点 w 使 C union {w} 仍然合法，即“一步极大”（1-maximal）；现已改为包含极大，并保留下面的反例解释两者为何不同。Alg3 和标准 Alg4 删除被更大合法团包含候选的后处理符合目标定义。

反例取 tau = 0.6，四个顶点 a、b、u、v 在结构上构成团，并令

```text
sim(a,b) = 0.6
sim(a,u) = sim(b,u) = 0.5
sim(a,v) = sim(b,v) = 0.5
sim(u,v) = 1.0
```

此时 {a,b} 合法；分别加入 u 或 v 后平均值为 1.6/3 < 0.6，因此 {a,b} 满足当前 TeX 的一步极大定义。但四点团的相似度总和为 3.6，平均值为 3.6/6 = 0.6，所以 {a,b} 又被一个更大的合法团包含。全局 subset pruning 会删除它。

因此，maximal 的语义不再是待选项。TeX 的问题定义和正确性证明已经改为“不存在任何合法严格超集”；Alg4 的输出论证也据此完成审计。仅检查无合法单点扩展的候选不能直接输出。全局 subset pruning 可以实现包含极大过滤，但其正确性依赖前序搜索完整生成所有可能作为合法超集的团；canonical 搜索已通过独立 oracle 验证这一前提，Alg2/Alg3 的最终正式实验仍需遵循相同的完整集合检查。

### 1.2 Alg4 的论文版本与实验入口已统一

标准入口现在是 `src/alg4-raw.cpp`，对应 canonical DFS；旧 visited-DFS 和旧分层实现完整保存在 `no-use/legacy-alg4/`。论文不再描述 level-synchronous expansion 或浮点 sorted-suffix break。旧 `build_ablation.sh` 针对已不存在的宏，不能继续用来声称生成有效 Alg4 消融版本；新的机制实验应直接比较 Layered、Visited-DFS 与 Canonical 三种生成策略。

## 2. 可借鉴的外部研究

### 2.1 极大团枚举

Eppstein、Loffler 和 Strash 将 degeneracy ordering 与 Bron--Kerbosch 结合，在退化度为 d 的稀疏图上达到 O(d n 3^(d/3)) 时间。这说明结构分解和低退化局部子问题应继续作为 Alg1/Alg3 的基础，而不是只使用全局度排序。

Uno 等人的 reverse-search MCE 为每个极大团定义唯一父团，从而形成无环枚举树。这个思想比“生成后哈希去重”更适合 Alg4：单调路径定理恰好能为每个合法语义团构造至少一个合法父团，如果进一步固定一个 canonical deletion，就能得到唯一父状态。

ParMCE 通过按顶点拆分子问题、递归产生并行任务和 work stealing 改善负载均衡，并给出相对高效顺序算法的 work-efficiency。GPU MCE 的研究还指出，逐层 BFS 会因深层状态爆炸而受限，DFS 独立子树更易控制内存。这与当前 level-synchronous Alg4 在中低 tau 下的状态膨胀直接对应。

### 2.2 非单调稠密子图搜索

FastQC 对 maximal quasi-clique 使用 branch-and-bound，并强调剪枝规则必须与 branching strategy 联合设计，而不是只不断叠加局部上界。虽然 quasi-clique 的约束与 ACMSC 不同，但“先构造覆盖所有答案的搜索树，再用必要条件反复收紧分支”的方法可以迁移到 Alg3 和 Alg4。

近期的 hybrid branching MCE 工作将顶点分支和边分支组合，并使用 early termination 直接完成某些分支。对 ACMSC 而言，边分支尤其自然，因为任何平均值至少为 tau 的团都存在一条相似度至少为 tau 的边，可把高相似边作为语义搜索的根。

### 2.3 带属性社区搜索

PVLDB 的 ACQ 和 ATC 工作同时考虑结构凝聚性与属性相关性，但它们分别以 query-based k-core/keyword cohesion 和 attributed truss 为目标，不枚举本项目定义的全部 ACMSC。因此它们适合作为应用质量对照，不适合作为“同一输出问题”的运行时间基线。

## 3. Alg4 的推荐改进：Canonical MonoSearch

### 3.1 用单调路径定义唯一父状态

对大小为 k 的合法团 C，记

```text
S(C)       = sum_{u<v in C} sim(u,v)
a_C(v)     = sum_{u in C\{v}} sim(u,v)
avg(C)     = S(C) / choose(k,2)
```

所有 a_C(v) 的平均值为 2S(C)/k = (k-1)avg(C)，因此至少存在一个顶点 v 满足

```text
a_C(v) <= 2S(C)/k.
```

删除这样的 v 后有 avg(C\{v}) >= avg(C) >= tau。这给出了单调路径定理的反向形式。固定全局顶点序，并把满足该条件的最小序顶点定义为 d(C)，再定义

```text
P(C) = C \ {d(C)}.
```

则每个大小至少为 3 的合法团都有且只有一个合法父团。重复应用 P 最终到达一个相似度至少为 tau 的二元团。所有合法团因此形成由高相似边出发的森林。

正向搜索 C -> C union {v} 时，只接受满足 P(C union {v}) = C 的孩子。这样同一个团不会再通过不同插入顺序生成，不需要 per-layer dedup 或跨根 visited hash。当前层同步方法对大小为 k 的团最多可能处理其多条、甚至阶乘级的合法插入路径；canonical parent 把已接受状态数降为合法团数 |F_tau| 本身。

canonical parent 只负责完整且唯一地枚举合法团，不直接判定包含极大。一个合法团即使没有合法单点扩展，甚至没有 canonical child，仍可能被更大的合法团包含。因此，搜索结束后仍需在全部合法候选之间执行包含过滤，或者另行证明一个与全局包含过滤等价的输出机制。

该方案不能消除低 tau 下合法团集合本身的指数规模，但可以消除路径重复。DFS 实现的工作内存从“最大一层全部状态”降为搜索栈、线程局部候选集和输出结构；并行时按 canonical 边根或浅层子树分派任务，再采用 work stealing。

### 3.2 多步扩展 surplus 上界

令边 surplus 为 w(u,v) = sim(u,v) - tau，则

```text
W(C) = sum_{u<v in C} w(u,v).
```

对候选集合 P 中的扩展集合 R，有精确分解

```text
W(C union R)
  = W(C)
  + sum_{v in R} [acc_C(v) - tau |C|]
  + sum_{u<v in R} w(u,v).
```

当前 W-pruning 只检查 |R|=1。可对每个可能的扩展大小 r 构造放松上界

```text
UB_r(C)
  = W(C)
  + Top-r sum of {acc_C(v) - tau |C| : v in P}
  + Top-choose(r,2) sum of {max(0,w(u,v)) : u,v in P, (u,v) in E}.
```

该式忽略了“选中的边必须来自同一组 r 个顶点”，所以一定不低估真实最优值。若所有 r 的 UB_r(C) 都小于 0，则不存在任何合法后代，可直接剪去整个状态。更紧的版本可为每个候选 v 预存其前 r-1 个正 surplus 邻边，用半度数和形成 vertex-aware upper bound。

理论上，这一上界覆盖了“一个顶点暂时不可行，但多个顶点联合后重新可行”的非单调情况，比单步 W-pruning 安全且更完整。计算上不应在每个状态完整排序；可使用父状态继承的有序候选、桶化上界或仅在候选宽度超过阈值时启用。

### 3.3 从 level-synchronous 改为并行 DFS

保留“按团大小分层”有利于论述，但不必要求物理执行也保存整层。推荐执行模型是：

1. 枚举 sim(u,v) >= tau 的结构边作为根，并按退化序分配唯一所有权。
2. 每个根执行 canonical DFS，只生成具有正确父状态的孩子。
3. 浅层宽分支拆成任务，使用 work stealing；深层保持线程局部 DFS。
4. 只记录输出候选及必要的包含极大验证信息，不保存整层 live states。

这样仍然由单调路径定理保证完备性，但避免 BFS/level-synchronous 在中低 tau 下的峰值内存。

### 3.4 Alg3/Alg4 自适应组合

低 tau 时 Alg4 的合法中间团集合 |F_tau| 很大，即使唯一生成仍可能慢；Alg3 的成本主要由结构极大团数量和团内组合数决定。可以在预处理阶段采样少量退化根，估计：

```text
semantic selectivity q_tau
平均候选窗口宽度
估计合法状态/输出比
结构极大团大小分布与重叠率
```

若预计 Alg4 的 live-state/output ratio 很高，则选择 StrSub；若高 tau 使候选窗口迅速收缩，则选择 Canonical MonoSearch。论文可以把它表述为一个可解释的 algorithm portfolio，而不是声称单一算法在所有 tau 上占优。更进一步，可在某个 canonical DFS 子树候选宽度过大时切换到局部 StrSub，但该混合方案需要额外证明唯一所有权。

### 3.5 Alg4 尚未实现但仍可行的优化

按推荐顺序，尚有三个安全方向。它们都不能仅凭证明声称“实际更快”，必须在完全输出相同的前提下通过本机基准后才可进入标准版。

1. **多步 surplus 放松上界。** 第 3.2 节的 `UB_r` 独立选择最佳顶点边际与最佳候选内部边，因此只会高估真实可达 surplus；只有对所有 `r` 都严格小于 0 时才剪枝，不存在漏解反例。风险是构造上界本身可能比它省下的搜索更贵，适合只在候选宽度较大时启用。
2. **包含过滤的无假阴性签名。** 为每个候选团保存固定宽度 OR-signature。若 `sig(C)` 中存在 `sig(D)` 没有的位，则 `C` 不可能是 `D` 的子集；通过签名的候选仍执行精确 sorted-merge 检查。哈希碰撞只产生额外精查，不会漏掉真实包含关系。
3. **浅层 canonical 子树任务拆分。** canonical 父关系使不同子树状态不相交，因此把浅层已接受孩子复制成独立任务不会重复或漏掉状态。代价是复制 accumulator/scratch 会增加内存，应设置深度和候选宽度门槛，并继续受 16 GiB 上限约束。

本轮已经实现一个无争议的小优化：撤掉每个状态的候选排序。浮点 sorted-suffix break 被移除后，排序不再触发任何成批剪枝，也不影响 canonical 接受条件；删除它严格减少排序工作，不改变状态集合。未采用的方向包括在线直接输出和结构容器唯一所有权，因为目前没有证明它们等价于全局包含过滤。

## 4. 其他算法的可选改进

### 4.1 Alg3：已落地的安全层上界与无位宽限制组合枚举

当前标准版 `src/alg3-raw.cpp` 已加入逐顶点层上界。设结构极大团 `M` 的大小为 `m`；这里的 `m` 只是当前 Phase 2 宿主团的顶点数，不是数据集顶点数，也不限制邻接数或输出数。对每个顶点 `v`，令 `q_v(k)` 为 `v` 在 `M` 内最大的 `k-1` 条关联相似度之和，再取所有 `q_v(k)` 中最大的 `k` 个，则任意大小为 `k` 的子集 `S` 都满足

```text
2 * simSum(S) <= sum_{v in S} q_v(k) <= TopKSum_v q_v(k),
avgSim(S) <= TopKSum_v q_v(k) / (k * (k-1)).
```

因此只有该上界严格小于 `tau` 时才跳过整层。该规则不假设平均约束具有单调性，也没有“单点不可行但多点恢复”的反例：它直接对目标大小 `k` 的所有子集取上界。实现对上界累加与除法向正无穷方向保守舍入，避免浮点低估造成错误剪枝。穷举 oracle 已检查 225,000 个随机 size-layer，没有发现一次低估真实最优值。

组合表示也已改成按宿主团大小选择：`m<=63` 使用原生 `uint64_t`，`64<=m<=127` 保留双字 Gosper 路径，`m>127` 使用动态 64-bit word 数组和精确字典序组合生成。原版的 `assert(m<=127)` 已撤销，没有换成新的数量上限。256 顶点完整宿主团的集成测试通过；测试实际处理 32,640 个二元子集并返回唯一预期 ACMSC。另一个 600 顶点完整团（每个顶点邻接数 599）返回唯一的 size-600 ACMSC，动态分层统计正确报告 size 600，不再受原先 512 桶统计数组影响。支持几百邻接意味着不会因 mask 或统计数组位宽崩溃、截断或漏报层数；精确子集枚举的最坏情况仍然保持其固有的指数复杂度。

标准版替换前已完成全量集合交叉验证。WN18RR、`tau=0.6` 下 Alg3 与 canonical Alg4 都输出 9,724 个结果，规范化集合比较为 Missing=0、Extra=0。FB15K-237 的 `tau=0.6` 与 `tau=0.8` 也与 canonical Alg4 完全一致；前者由原版 85.237 秒降至 67.864 秒，后者由 31.431 秒降至 16.747 秒。所有验证使用 32 线程和 16 GiB 进程内存上限。180 秒仅用于筛选对比参数：只选择原版自身能在 180 秒内完成的参数，不是对算法施加三分钟完成要求。标准程序默认不限运行时间和输出数量。

尚未实现 minimal-change 增量求和和 include/exclude branch-and-bound。前者可能减少每个子集的算术量，但会改变浮点累加顺序并增加控制开销；后者的状态维护成本可能抵消剪枝收益。它们只有在另建原型、保持完整输出集合相同并稳定快于当前标准版后才值得进入主实现。结构容器唯一所有权仍没有“每个语义团恰有一个 owner”的证明，存在漏解风险，本轮明确不实现；全局 subset/dedup 继续保留。

### 4.2 Alg2：保持朴素基线，不把它优化到失去基线意义

Alg2 的角色应固定为“直接将平均约束嵌入无 pivot BK 的直觉方案”。可以另外实现 SemBK+UB，用与 Alg4 相同的多步 surplus 上界展示“单有上界仍不等于单调路径搜索”，但不要替换论文中的 SemBK 基线。这样 Alg2 继续承担设计动机，而 SemBK+UB 作为分析变体说明 Alg4 的收益来自搜索空间组织与剪枝的共同作用。

## 5. 外部 baseline 选择

### 5.1 主效率表中的算法与参照

按主表价值排序如下。

| 排名 | Baseline | 定位 | 是否进入主效率表 |
|---:|---|---|---|
| 1 | SemBK（Alg2） | 同一 ACMSC 输出问题的直接、朴素精确改造 | 必须；它是最清楚的设计动机基线 |
| 2 | StructBK（Alg1） | 唯一的纯结构 MCE 参照，不执行语义枚举 | 保留；明确标注输出不同，只显示结构成本基准 |
| 3 | Generic-BB | 通用 include/exclude + 已证明的 surplus 上界，不使用 canonical parent | 建议；用于隔离“专用唯一父搜索”的贡献 |
| 4 | MIQCP/CP-SAT Oracle | 小图精确枚举/反例验证 | 只作正确性 oracle，不作性能 baseline |

这里的“相同后处理”具体指：外部结构 MCE 先输出每个结构极大团 M；随后在每个 M 内枚举满足平均约束的子集，做团内包含过滤；合并所有 M 的候选，去重，并执行全局包含极大过滤。ELS-Post、ParMCE-Post 和 MACE-Post 只替换第一步，后四步完全相同。该流水线本质上就是“不带 Top-Edge 等优化的 Alg3”，而且语义子集枚举通常占大头；同时比较三种 MCE 引擎不会形成三个独立 ACMSC baseline，只是在重复测 Alg3 的结构前端。

主效率表保留当前 StructBK 作为唯一的纯结构参照是合理的：它显示在完全不承担语义约束、语义子集枚举和包含过滤时，标准结构 MCE 的成本处于什么量级。表头和正文必须明确它不解决 ACMSC、输出不可直接比较，不能把其时间解释成 ACMSC baseline 的胜负。没有必要再加入 ELS、ParMCE、MACE 等多个纯结构实现；这些变体主要比较传统 MCE 工程，容易偏离论文重点。StructBK 同时继续用于结果质量实验，展示纯结构极大团的语义异质性。

### 5.2 相邻问题 baseline，只用于结果质量

| 排名 | Baseline | 与 ACMSC 的差异 | 合理比较指标 |
|---:|---|---|---|
| 1 | PairSim-MCE | 仅保留 `sim(u,v) >= tau` 的边后枚举极大团，要求每一对都过阈值 | 输出数量、规模、覆盖率、均值/最小相似度分布、运行时间 |
| 2 | StructBK | 完全忽略语义，仅保证结构极大 | 语义一致性、规模、覆盖率；不做同任务效率胜负 |
| 3 | ACQ 或 ATC（二选一） | 查询式 attributed core/truss，不做全量 ACMSC 枚举 | DBLP 案例中的主题纯度、结构凝聚性、F1（若有真值） |
| 4 | FastQC/Quick+ | 枚举 quasi-clique，结构目标不同 | 只借鉴 branch-and-bound，不建议实现为实验对手 |

PairSim-MCE 最值得加入：它和 ACMSC 使用同一图、同一相似度和同一 tau，却把“平均约束”替换成“每条边约束”，能够直接说明平均模型找出的团在规模、覆盖与内部相似度尾部上有何不同。ACQ/ATC 的查询和输出定义差异更大，只应出现在结果质量或案例分析中。不同输出定义的方法不能用“我们更快且结果相同”表述。

### 5.3 baseline 与消融的边界

- 旧 Layered Alg4、Visited-DFS 和 Canonical DFS 是同一方法的生成策略，属于机制实验，不是外部 baseline。
- Generic-BB 若由本项目自行实现，是“通用搜索控制组”；它可以进入主效率表，但不能包装成外部已有 ACMSC 系统。
- ELS-Post、ParMCE-Post、MACE-Post 共享 Alg3 后处理，属于结构 Phase 1 的工程替换；当前已有一个标准 StructBK 参照，不再加入这些变体。
- PairSim-MCE、StructBK、ACQ/ATC 改变了结果定义，属于结果质量对照，不与 canonical、Top-Edge 等算法消融重合。

## 6. VLDB 实验重构

### 6.1 实验数量判断

VLDB regular research paper 当前上限为 12 页（参考文献除外），官方要求的是核心数据管理问题、规模性和证据覆盖，没有规定实验编号数量。官方 reproducibility 指南强调三个方面：提供完整系统和配置、能在不同环境复现、所有中心结论都有实验覆盖。因此 4--6 个有明确研究问题的实验组通常比 8--9 个彼此重叠的小实验更有说服力。

当前 343 个任务并非绝对过多；真正的问题是：主表、任务 CSV 和脚本使用不同 tau，诊断和消融重复覆盖相同机制，线程数超过硬件物理能力，且 Exp-2 没有真实切换规模数据。建议将实验收敛为以下 6 个 RQ；第六项同时承担模型质量和案例分析，不再另开零散实验。

### 6.2 新实验结构

#### RQ1：正确性与端到端效率

目标：三种核心算法及外部精确基线是否枚举相同答案，各自在什么 tau 区间占优。

- 方法：StructBK（仅结构参照）、SemBK、StrSub、Canonical MonoSearch、Generic-BB。旧 Layered/Visited Alg4 不进主表，只在 RQ4 出现。
- 数据集：选择 6 个代表性图，覆盖低/高退化度、不同结构团规模和真实/合成语义向量。初步建议 DS2、DS4、DS5、DS7、DS8、DS9；DS1 和 DS10 放入规模实验。
- tau：每个数据集使用 q20、q50、q90 三个相似度分位点。若 q90 输出退化为空，再降为 q80，并在实验前按统一规则确定，不能按算法表现单独挑选。
- 指标：end-to-end time、preprocess time、enumeration time、peak RSS、输出数、最大/平均团大小、time per output。
- 重复：确定性算法计时运行 3 次，报告中位数和范围；TLE/OOM 单独报告。
- 正确性：小图用 MIQCP/CP-SAT oracle；大图比较规范化输出哈希，而不是只比较计数差小于 3。

#### RQ2：tau 适用区间与输出敏感性

目标：解释 Alg3/Alg4 的 crossover，而不是只展示若干离散胜负。

- 在 3 个代表数据集上扫描 q10、q20、q30、q50、q70、q80、q90、q95。
- 只比较 SemBK、StrSub、Canonical MonoSearch 和自动选择器，不重复所有外部基线。
- 同时画 time、peak states、raw states/output、pruned ratio 和 output count。
- 用 live-state/output ratio 验证为什么 Alg4 在低 tau 慢，并验证 canonical parent 是否减少重复生成。

#### RQ3：图规模与内存可扩展性

目标：验证随图规模和输出规模增长的行为。

- 使用 DBLP 和 Amazon 的 10%、25%、50%、75%、100% 五个固定嵌套子图。
- 每个子图必须有匹配的重编号向量文件，并把 graph/vector 路径作为显式 CLI 参数，不再只传 dataset ID。
- 固定 q50 和 q90 两个阈值；比较 StrSub、Canonical MonoSearch、最佳外部精确基线。
- 报告 vertices、edges、degeneracy、结构极大团数、ACMSC 输出数、时间和 peak RSS。

#### RQ4：机制验证，合并 diagnostics、ablation 和 engineering

目标：每个机制是否减少了它声称减少的工作量。

- Alg4 生成策略：旧 Layered、旧 per-root Visited-DFS、Canonical DFS；若 multi-step UB 最终实现，再比较 Canonical 与 Canonical+UB。
- Alg4 的 W 判断、canonical parent 与 exact rollback 都涉及可行状态定义或唯一性，不做会改变正确性的“关闭式消融”。
- Alg3 变体：无 Top-Edge、无 LocalMax、原版；vertex-aware bound 只有在独立原型通过正确性与速度验收后再加入。
- 只选 3 个能体现低/中/高 tau 行为的数据集，每个取 q20、q50、q90。
- 报告时间之外的直接机制指标：generated states、accepted unique states、UB prunes、duplicate paths、subset candidates。
- bitmap、reorder、incremental acc 等纯工程优化放在同一小表或附录，不再单独占一个主实验编号。

#### RQ5：并行扩展性

目标：证明并行实现的 work distribution，而不是测试超额订阅。

- 只使用 1、2、4、8、16、32 线程；当前机器只有 32 个硬件线程时，不测试 64/128。
- 选一个 Alg3 较强和一个 Alg4 较强的数据集/阈值组合。
- 报告 speedup、parallel efficiency、每线程任务数、工作量方差和 peak RSS。
- 若并行不是论文主要贡献，可将本实验压缩为一张图；只有需要隔离 Alg3 Phase 1 并行性时才在附录加入 ParMCE-Post。

#### RQ6：结果质量与案例分析

目标：说明平均约束相较纯结构团和 pairwise-threshold 团发现了什么不同结构。

- DBLP 上比较 StructBK、PairSim-MCE 和 ACMSC。
- 除 3--5 个代表案例外，报告规模分布、avgSim 分布、主题纯度、覆盖作者数和冗余率。
- 若有可靠 ground truth，可参考 attributed community search 使用 precision/recall/F1；没有 ground truth 时不要只依赖主观案例。

### 6.3 应删除或降级的旧实验内容

- 不再单独保留“Search Diagnostics”实验；合入 RQ2/RQ4。
- 不再单独保留完整“Engineering Optimizations”实验；除非工程优化本身是主要贡献，否则放附录。
- 不在所有数据集、所有 tau 上运行 stats 版本；诊断只需要代表性困难实例。
- 不测试超过硬件线程数的 64/128 线程。
- 不重复运行与 tau 无关的 StructBK。
- 不把只有 L1/L6 且没有正确切换图数据的结果称为 scalability。
- 纯定性 DBLP 案例不是必需主实验；页数紧张时放附录或 artifact。

### 6.4 应新增的证据

- peak RSS：层同步 Alg4 的关键风险是内存，不报告内存会遗漏主要 tradeoff。
- output-sensitive 指标：time/output、states/output、延迟到首个结果。
- 独立正确性 oracle 和全量输出哈希。
- 算法 regime map：以 tau selectivity、degeneracy、最大结构团大小预测 Alg3/Alg4 选择。
- 预处理与枚举时间分离，同时保留 end-to-end 总时间。
- 失败结果的统一 TLE/OOM 协议和可复现命令。

## 7. 推荐实施顺序

1. [已完成] 将 TeX 的 ACMSC 定义改为包含极大，并修正 NP 成员证明与 Alg4 输出论证。
2. [已完成] 将 canonical DFS 设为唯一标准 `src/alg4-raw.cpp`，同步论文伪代码与叙述。
3. [已完成] 建立独立 brute-force oracle；40,001 个实例的合法状态、唯一性和最终极大输出全部一致。
4. [已完成] 证明 canonical parent 的存在性、唯一性、完备性和无重复性，并用 Alg3 对 DS7 完整集合交叉验证。
5. 证明 multi-step surplus upper bound 的安全性，再决定低成本实现。
6. 用少量 pilot 数据估计 crossover，确定 RQ1 的三个 tau 分位点。
7. 修复规模数据的图/向量对应关系和显式路径接口。
8. 最后生成统一任务清单、运行实验并由脚本直接生成论文表图。
