# Final Paper Data

This directory contains only the final numerical values used in the paper.
Each CSV is a single current version; raw data, logs, trial archives, and
superseded results are intentionally excluded.

| File | Paper use |
| --- | --- |
| `dataset_inventory.csv` | Dataset inventory in the experimental setup |
| `main_runtime.csv` | RQ1 runtime table and structural output counts |
| `threshold_sensitivity.csv` | RQ2 threshold-sensitivity results |
| `bkplus_vertex_bound_four_graph.csv` | BKPlus vertex-bound ablation |
| `scale_regime.csv` | RQ3 graph-size scalability results |
| `parallel_scaling.csv` | RQ4 parallel-scaling results |
| `alg3_mechanism_counters.csv` | StrSub pruning counters in RQ5 |
| `alg4_state_contraction.csv` | MonoSemMCE state-contraction counters in RQ5 |
| `alg3_ablation_runtime.csv` | StrSub pruning ablation table |
| `alg4_generation_ablation.csv` | MonoSemMCE generation ablation table |
| `highsim_generation_four_graph.csv` | Four-graph canonical-state timing and memory comparison |
| `engineering_ablation.csv` | Selected method-specific engineering comparisons |
| `engineering_profile_selection.csv` | Complete 31-configuration engineering sweep |
| `alg3_phase_attribution.csv` | StrSub phase attribution in RQ4 |
| `result_distribution.csv` | RQ6 output count and size distribution |
| `group-recovery.csv` | RQ7 definition and external-family comparisons |
| `group-recovery-detail.csv` | RQ7 per-group definition comparison |
| `ogbn-arxiv-case-similarity.csv` | RQ7 ogbn-arxiv case-study similarities |
| `ogbn-arxiv-case-study.csv` | RQ8 PIR case-study summary |
